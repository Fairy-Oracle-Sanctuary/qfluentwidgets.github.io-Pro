Python examples target `qfluentwidgets_pro`. Run the fragments after creating `QApplication`; `self` refers to your window, and resource paths must point to your own assets. See the [installation page](/pages/install/).

QFluentWidgets provides the `FluentTranslator` class, which is used to translate the text of built-in components. By default, the translation follows the system language.


```python
from PySide6.QtWidgets import QApplication
from qfluentwidgets_pro import CalendarPicker, FluentTranslator

app = QApplication([])

# create an translator instance that has the same lifecycle as the app
translator = FluentTranslator()
app.installTranslator(translator)

w = CalendarPicker()
w.show()
app.exec()
```


You can specify the target language by providing `QLocale` instance:

```python
from PySide6.QtCore import QLocale

# Simplified Chinese
FluentTranslator(QLocale(QLocale.Chinese, QLocale.China))

# Traditional Chinese
FluentTranslator(QLocale(QLocale.Chinese, QLocale.HongKong))
```


## Contribute translation
The translation files are stored in `qfluentwidgets_pro/_rc/i18n`. To add a language:
1. Copy the English template `qfluentwidgets.en_US.ts` and rename it for the target language, for example `qfluentwidgets.ja_JP.ts`. Update the `language` attribute of the `<TS>` tag:

   ```xml
    <TS version="2.1" language="ja_JP">
   ```

2. Open `qfluentwidgets.ja_JP.ts` using Qt Linguist and complete the translation work.
3. Export the `qfluentwidgets.ja_JP.qm` file.
4. Create a Pull Request.

From the repository root, the batch script can synchronize TS files, compile QM files and rebuild resources without contacting a translation service:

```shell
python scripts/translate_ts.py --all --skip-translate --build
```

For automatic translation, configure the service as described in the script and remove `--skip-translate`. Do not commit local API credentials.

These examples target [Qt-Fluent-Widgets](https://github.com/Fairy-Oracle-Sanctuary/Qt-Fluent-Widgets). Follow the [installation guide](/pages/install/#c-integration), create `QApplication`, and call `Q_INIT_RESOURCE(resource)` first. In these fragments, `parent` is your window pointer. Add widgets to your layout and replace asset paths with your own files.

```cpp
#include <qtfluentwidgets.h>
#include <QDebug>
#include <memory>
```

## C++ Load widget translations

```cpp
Q_INIT_RESOURCE(resource);
auto* translator = new qfw::FluentTranslator(QLocale(QLocale::Chinese, QLocale::China), QCoreApplication::instance());
QCoreApplication::installTranslator(translator);
auto* picker = new qfw::CalendarPicker(parent);
picker->setDate(QDate::currentDate());
```

## C++ Load your application translations

```cpp
auto* translator = new QTranslator(QCoreApplication::instance());
if (translator->load(QStringLiteral("translations/myapp_zh_CN.qm"))) {
    QCoreApplication::installTranslator(translator);
}
```

Widget translations live in `qtfluentwidgets/resources/i18n`. Edit TS files in Qt Linguist, compile matching QM files with `lrelease`, add them to `qtfluentwidgets/resources/resource.qrc`, then rebuild. Only bundled language files are available; not every Python translation has been ported to C++.

```shell
lrelease qtfluentwidgets/resources/i18n/qfluentwidgets.zh_CN.ts -qm qtfluentwidgets/resources/i18n/qfluentwidgets.zh_CN.qm
```
